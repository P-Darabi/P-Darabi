## Featured Projects

### Solar Panels Defect Detection

An end-to-end Computer Vision system for detecting thermal anomalies in photovoltaic panels using **YOLOv9**.

Combines deep learning, thermal image analysis, backend development, and deployment through a **FastAPI REST API** and Dockerized environment.

* 7,700+ labeled thermal drone images
* YOLOv9-based object detection
* Thermal image analysis
* FastAPI REST API
* Dockerized deployment
* Renewable energy monitoring

**[View Project on GitHub](https://github.com/P-Darabi/SolarPanelsDefectDetector)**

---

### Helmet Violations Detection & Tracking

A Computer Vision system for detecting and tracking motorcycle and scooter riders without helmets.

Combines **object detection, tracking, license plate recognition, and OCR** into a practical video analysis pipeline.

* Helmet violation detection
* Object tracking
* License plate detection
* OCR-based information extraction
* Structured output generation

**[View Project on GitHub](https://github.com/P-Darabi/Helmet-Violations)**
